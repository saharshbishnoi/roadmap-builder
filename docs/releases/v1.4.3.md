# Roadmap Builder 1.4.3

A guide you can open without leaving the roadmap, a theme switch on the toolbar, and every video re-recorded
to match.

There is no 1.4.2 release: that tag's build stopped on a test that measured the Guide dialog while it was
still animating into place. The app is the same; 1.4.3 fixes the test.

## New since 1.4.1

- **Guide as a large dialog.** Guide, the last button on the toolbar, opens a large dialog at the top of the window with the steps for each part of the app, each beside its video. It replaces the separate Help page.
- **Videos that match the theme.** The dialog plays the dark videos when the app is dark and the light ones when it is light. The old Help page followed the computer's setting instead, so the wrong set could show.
- **Light / dark on the toolbar.** A Dark / Light button beside Guide switches the theme; it is the same setting as Theme in Properties.
- **Dialogs keep a square accent.** With Rounded cards on, only the bottom corners of a dialog round; the coloured strip along its top stays square.
- **MIT licence.** `LICENSE` and `THIRD-PARTY-LICENSES.md` are in the repository; the second lists what is packaged with the app separately from what is only used to build it.
- **Videos re-recorded.** The ten guide videos and the product film show the new toolbar and the Guide dialog, with the longer narration introduced in 1.4.1.

## Known limits

- The guide videos and the film are narrated by a synthetic voice; nobody has listened to this recording.
- In the film, the Guide dialog shows the steps without videos, because the film is recorded from a copy of the app that has no guide videos beside it.
- The colours in the "Randomise colours" scenes are random, so they differ between the light and dark guide videos and from one build to the next.
- The zip does not yet include `LICENSE` or `THIRD-PARTY-LICENSES.md`; it carries the shorter `vendor/THIRD-PARTY.txt` and the font licence texts.
- Tested in Chrome only.
