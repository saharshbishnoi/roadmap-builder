# Roadmap Builder 1.4.1

The 1.4 features, with the guide videos and the product film re-recorded to show them. This is the first
release whose files are all built and attached by the pipeline: the app zip and the 4K film included.

The narration has been rewritten throughout. Each line now explains what a feature is for as well as what
it does, in fuller, more conversational sentences, so the videos run longer than before.

## New in 1.4

- **Slim header.** A single bar with a short heading and a small tagline. Its size and font are set under Header in Properties. The date range line is gone.
- **Date chip on the right.** It can be switched off, or kept on screen but left out of exports, where it reads "As at" the day of the export.
- **Rename the Cards heading** under Header; the tab of the right panel carries the same name.
- **Randomise colours.** A fresh, matched set of colours for the header, the highlight and every workstream, built around one random hue in one of six schemes and chosen to read on both themes. Each press is one Undo step. Light / dark switches the theme to check an idea both ways.
- **Timeline settings in Properties.** Start year, years shown and the today line colour moved out of the header.

## Since 1.3

Everything in 1.3.0 is included: the full-window schedule, the Properties panel, the JSON editor panel with
line numbers and formatting, the image of this view, the view-only standalone page, fitting the timeline to a
row, pinned floating cards, and Help in its own window.

## In this release

| File | What it is |
|---|---|
| `roadmap-builder.zip` | The whole app with its ten guide videos. Unzip and open `index.html`; no server needed |
| `roadmap-builder-film-4k.mp4` | The product film, 3840 x 2160, with chapter markers |
| `roadmap-builder-film-1080p.mp4` | The product film, smaller copy for sharing |
| `roadmap-builder-film.srt` | Subtitles for the film |
| `roadmap-builder-film-chapters.txt` | The film's chapters and their start times |
| `roadmap-builder-guide-videos.zip` | The ten guide videos on their own (five chapters, light and dark, 3840 x 2160), with subtitles |
| `SHA256SUMS.txt` | Checksums of the files above |

## Known limits

- The guide videos and the film are narrated by a synthetic voice; nobody has listened to this recording.
- The colours in the "Randomise colours" scenes are random, so they differ between the light and dark guide videos and from one build to the next.
- Tested in Chrome only.
